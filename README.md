# 记忆相册整理器

为支持 `SKILL.md` 的助手提供照片整理工作流：同一场景只精选一张代表作，其他版本保存在可恢复回忆仓。

由视觉助手比较构图、光线和主体表现，Python 脚本执行可靠复制、校验与恢复。不同焦距、曝光的同一个日落也应整体比较，不拆成许多小组。

## 使用

将仓库放入助手的技能目录，文件夹命名为 `photo-album-organizer`，调用：

> 使用 $photo-album-organizer 整理我的相册，同一场景只留一张最好看的，其余放入回忆仓。

入口为 [SKILL.md](SKILL.md)，Python 3.10+ 脚本不需要第三方依赖，命令见 [执行说明](references/workflow.md)。

脚本不具备自动场景识别或审美能力，需要助手看图后生成计划。默认复制，不节省原片占用空间；回忆仓不是系统回收站，不自动清空。脚本不联网；调用视觉助手的数据处理取决于所用产品。仓库不含个人照片或相册清单。

## 测试
